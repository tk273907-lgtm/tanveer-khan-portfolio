## 💻 Run This Portfolio Locally

This is a static website, so no backend or build system is required to view the portfolio.

### 1. Clone the repository

```bash
git clone https://github.com/tk273907-lgtm/tanveer-khan-portfolio.git
```

### 2. Open the project

```bash
cd tanveer-khan-portfolio
```

### 3. Run the website

Simply open:

```text
index.html
```

in your browser.

You can also open the project in VS Code and use a local development extension such as Live Server.
